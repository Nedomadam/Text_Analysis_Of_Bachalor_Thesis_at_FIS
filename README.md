# Text_Analysis_Of_Bachalor_Thesis_at_FIS
Semestral project for the Text Analytics course, applying basic text analytics and NLP techniques to analyze AI-focused academic theses.

# This repository contains
1. Code for scraping the data - Data_scraping.ipynb
2. Code for the main analysis - Main_analysis.ipynb
3. All theses used - downloaded_theses
4. 5 metadada files used: theses_metada.csv / theses_metadata_classified.csv / theses_metadata_classified_industry.csv / theses_metadata_classified_industry_technology.csv / theses_with_sentiment.csv
